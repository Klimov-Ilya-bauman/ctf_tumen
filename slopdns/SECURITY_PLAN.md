# План исправлений

Область: только каталог slopdns; сохранить API, DNS и формат синхронизации. Не менять соседние проекты и пользовательские данные.

1. Исправить повышение zone → org/service-account в общем RBAC и проверку организации назначения при переносе.
2. Устранить гонку проверки owner при изменении/удалении role binding, включая trusted revoke.
3. Добавить ограничение запросов до интроспекции и публичного входа; общий атомарный бюджет второго фактора по пользователю между challenge и чувствительными операциями.
4. Проверить DNS-бинарник и sync, строгую валидацию RDATA; исправить подтверждённые проблемы без удаления GPT/DNS-функциональности.
5. Добавить генерацию уникальных установочных секретов и рекомендации по TLS/ротации без отключения штатного CTF HTTP.
6. Регрессионные тесты, сборка, независимый повторный аудит; отчёт на русском с доказательствами и ограничениями.

Приёмка: запрещены повышение полномочий и перенос в неавторизованную организацию; легитимное наследование org → ресурс работает; owner не удаляется гонкой; MFA-бюджет не сбрасывается новым challenge; DNS/GPT и API сохраняют совместимость. Проверить go test/go vet, сборку и доступные интеграционные тесты. Не утверждать отсутствие всех уязвимостей без достаточной проверки бинарника.
